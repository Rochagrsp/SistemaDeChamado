# 🎫 Sistema de Chamados

Sistema simples de gerenciamento de chamados desenvolvido com Python e Streamlit.

## 🚀 Funcionalidades

- Abrir chamados
- Listar chamados
- Alterar status dos chamados

## 🛠️ Tecnologias

- Python
- Streamlit

## ▶️ Como Executar

Instale o Streamlit:

```bash
pip install streamlit
```

Execute o projeto:

```bash
streamlit run app.py
```

## 📌 Status dos Chamados

- Aberto
- Em andamento
- Finalizado

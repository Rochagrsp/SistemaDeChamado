# 🎫 Sistema de Chamados

Um sistema simples de gerenciamento de chamados desenvolvido com Python e Streamlit.

---

## 🚀 Funcionalidades

- Abrir chamados
- Listar chamados cadastrados
- Alterar status dos chamados
- Interface simples e interativa
- Armazenamento temporário usando `st.session_state`

---

## 🛠️ Tecnologias Utilizadas

- Python
- Streamlit

---

## 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/sistema-chamados.git
```

Acesse a pasta do projeto:

```bash
cd sistema-chamados
```

Instale as dependências:

```bash
pip install streamlit
```

---

## ▶️ Como Executar

Execute o projeto com o comando:

```bash
streamlit run app.py
```
